# Luddy Program Explorer

A responsive React/Vite implementation of the supplied Luddy Program Explorer design.

## Run locally

```bash
npm install
npm run dev
```

## Configure Ask AI

Copy `.env.example` to `.env`, add the Firebase web configuration for your project, and enable Firebase AI Logic in the Firebase console. Restart the development server after changing environment variables.

```bash
npm run dev
```

## Production build

```bash
npm run build
```

The site includes working program filters, expandable major cards, an accessible comparison table, a FAQ accordion, responsive layouts, and keyboard focus styles.
